# Content Engine

**9 agentic content-production skills** — the full short-form video pipeline:
trend sourcing → AI video generation → editing → multi-platform distribution,
plus the web-design content lane.

Built and cost-optimized in production across three channels and 100+ posts.
Every model recommendation comes with real cost-per-clip numbers and the
provider gotchas that burned render credits before we documented them.

## What's inside

### Source
| Skill | What it teaches |
|---|---|
| `reddit-reading` | Trend + content sourcing from Reddit, no browser needed |
| `rss-feeds` | RSS/Atom monitoring for topic pipelines |
| `competitor-news-monitor` | Watch named competitors, get cited digests |

### Produce
| Skill | What it teaches |
|---|---|
| `cloud-video-generation` | AI video gen with cost-per-clip A/B framework (real $/clip comparisons) |
| `content-edit-kit` | Screen-recording and content-video editing/captioning |
| `comfyui-mc-integration` | Remote ComfyUI orchestration from an agent |
| `web-design-pipeline` | AI-automated web design production |

### Distribute
| Skill | What it teaches |
|---|---|
| `youtube-cross-post` | Cross-post short-form video to YouTube |
| `referral-link-promotion` | Honest short-form promo patterns |

## Design principles

- **Cost-first** — every generation recipe states its price per output up front.
- **Gotchas are content** — the "this flag silently fails the whole job" notes
  are the most valuable lines.
- **Platform-neutral pipelines** — swap the render backend without rewriting.
